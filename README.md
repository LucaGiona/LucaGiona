Today I build websites, progressive web apps and small tools. I'm also training to become a qualified nurse, and a lot of my projects come straight out of that work: from the hospital ward and from the bar.

## Featured: HNO Learning App

**[Live](https://lucagiona.github.io/hno_miniapp/) · [Code](https://github.com/LucaGiona/hno_miniapp)**

I built this for my placement on an ENT (HNO) ward: a glossary of ~160 abbreviations and medical terms, plus flashcards and a quiz.

- Works **offline** after the first load (Service Worker) and installs to the home screen like an app
- Interface in **German, English and French**, so colleagues whose first language isn't German can use it too
- Plain HTML, CSS and JavaScript with native ES modules. No framework, no build step

I like keeping things simple and understandable: most of my apps run on plain HTML, CSS and JavaScript, with no framework and no build step.
